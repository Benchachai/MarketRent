# MarketRent - ระบบบริหารและชำระค่าเช่าแผงค้าออนไลน์ (GURU IT Solution)

เว็บแอปพลิเคชันและพอร์ทัลบริการออนไลน์สำหรับผู้ประกอบการและผู้เช่าแผงค้าตลาด พร้อม**ระบบหลังบ้าน (Officer Back-Office)** สำหรับเจ้าหน้าที่เทศบาล/อบต. พัฒนาขึ้นเพื่ออำนวยความสะดวกในการตรวจสอบสถานะรอบเดือน ชำระค่าธรรมเนียมเช่าแผงค้าตลาด แนบสลิปหลักฐานการโอนเงิน **ตรวจสอบและอนุมัติสลิปการชำระเงิน**, **ออกใบเสร็จรับเงินทางการตามแบบมาตรฐานท้องถิ่น**, และจัดการเรื่องร้องเรียน/คำร้องออนไลน์ ออกแบบโดย **GURU IT Solution Co., Ltd.** สอดคล้องตามมาตรฐานระบบเช่าแผงค้าท้องถิ่น (MarketRent อบต./เทศบาล) พร้อมดีไซน์ **Modern Vibrant Orange Theme** ผสานตราสัญลักษณ์ทางการของ GURU IT (สีน้ำเงิน-ส้ม) และระบบหลังบ้าน **Municipal Slate-Navy Theme** รองรับการใช้งานบนทุกอุปกรณ์ทั้งมือถือและเดสก์ท็อป

### 1. หน้าแรกของพอร์ทัล (Portal Landing Page - `index.html`)
- **หน้าเริ่มต้นของระบบ (Default Landing Page)**: หน้าต้อนรับหลัก มีแถบนำทางส่วนหัว (Locked Fixed Navbar) ตรึงอยู่ด้านบนสุดตลอดเวลา ไม่ขยับหรือเลื่อนหายไปตามการเลื่อนหน้าจอ พร้อมแสดงแบรนด์ **MarketPay** โลโก้ GURU IT และปรับลดเมนู "หน้าแรก" ที่ซ้ำซ้อนออก เพื่อความกระชับ สะอาดตา และทันสมัย โดยผู้ใช้สามารถคลิกตราสัญลักษณ์ MarketPay เพื่อกลับสู่หน้าเริ่มต้นได้เสมอ พร้อมแถบเมนูมือถือด้านล่าง (Mobile Bottom Nav)
- **แบรนด์และโลโก้**: แสดงตราสัญลักษณ์ทางการ **GURU IT Solution Co., Ltd.** (อักษร G และ URU สีน้ำเงิน, อักษร IT สีส้ม และ Solution Co., Ltd. สีเทา) สวยงาม คมชัด ถูกต้องตามสัดส่วนต้นฉบับ
- **Hero Section พร้อมสมาร์ตโฟนการ์ดม็อกอัป 3D (3D Smartphone Showcase Mockup)**: แบนเนอร์แสดงภาพถ่ายบรรยากาศตลาดสดเทศบาล แผงค้าผักผลไม้ แสงธรรมชาติโปร่งสบาย พร้อมเอฟเฟกต์การไล่เฉดสี Modern Vibrant Orange Gradient แนวนอน และการ์ดสมาร์ตโฟนจำลองแบบ 3D Perspective ฝั่งขวา (แสดงแบบภาพนิ่ง Static ชัดเจน สบายตา ไร้แอนิเมชันลอยรบกวนสายตา แสดงโลโก้ MarketPay, ตัวอย่างเมนู, ปุ่มเข้าสู่ระบบ และป้าย "✓ เชื่อมต่อบริการ อบต./เทศบาล" ที่จัดวางไม่ทับซ้อน) โดยบนหน้าจอมือถือและแท็บเล็ต (`max-width: 768px`) ระบบจะซ่อนการ์ดม็อกอัปนี้อัตโนมัติ เพื่อให้หน้าจอมือถือกระชับ คมชัด และอ่านง่าย
- **ระบบบังคับเข้าสู่ระบบก่อนใช้งาน (Require Login)**: เมื่อผู้ใช้กดปุ่ม **"เริ่มใช้งาน MarketPay ↗"** หรือคลิกบริการชำระเงิน หากยังไม่ได้ล็อกอิน ระบบจะเลื่อนหน้าจอลงมาไฮไลต์การ์ดเข้าสู่ระบบพร้อมแจ้งเตือนทันที
- **หมวดหมู่บริการออนไลน์**: เมนูด่วนเข้าถึงบริการชำระค่าเช่าแผง, ประวัติการชำระเงิน, ลงทะเบียนแผงค้าใหม่ และติดต่อ อบต./เทศบาล
- **ข่าวสารประชาสัมพันธ์**: แสดงประกาศการจัดสรรแผงค้าและกำหนดชำระค่าเช่าแผงประจำงวด พร้อมระบบพับเปิด-ปิดเนื้อหา (`<details>`)
- **เข้าสู่ระบบด่วน (Quick Login)**: ฟอร์มเข้าสู่ระบบหน้าแรกด้วย **เบอร์โทรศัพท์** และ **รหัสผ่าน** พร้อมปุ่มกดกรอกข้อมูลทดสอบอัตโนมัติ (`0812345678` / `123456`)
- **ระบบตรวจสอบการเข้าสู่ระบบแบบเข้มงวด (Strict Authentication)**:
  - ช่องที่ 1: **เบอร์โทรศัพท์** (เช่น `0812345678`)
  - ช่องที่ 2: **รหัสผ่าน** (Password ที่ตั้งไว้ตอนลงทะเบียน) พร้อมปุ่มไอคอนดวงตา (👁 / 👁‍🗨) ให้สามารถคลิกเปิด/ปิดเพื่อดูตัวเลขรหัสผ่านที่กรอกได้ทันที
  - **แจ้งเตือนความผิดพลาดแบบระบุสาเหตุ**:
    - กรณีไม่พบบัญชี: ป๊อปอัปแจ้งเตือน **"ไม่พบบัญชีผู้ใช้งาน"**
    - กรณีพบเบอร์โทรแต่รหัสผ่านผิด: ป๊อปอัปแจ้งเตือน **"รหัสผ่านไม่ถูกต้อง"**
- **ระบบนำทางอัตโนมัติ (Post-Login Redirection)**: เมื่อเข้าสู่ระบบสำเร็จ จะแสดงป๊อปอัปเครื่องหมายถูกสีเขียว (✓) ชัดเจน โดดเด่น บนพื้นหลังโปร่งแสงโทน Neutral มาตรฐาน (ไม่ย้อมพื้นหลังทั้งจอเป็นสีส้ม) พร้อมแถบความคืบหน้า (Progress Bar) สีเขียวละมุนตา แล้วนำทาง (Redirect) ไปยังหน้า **`account.html` (บัญชีของฉัน)** โดยอัตโนมัติ
- **สถานะเข้าสู่ระบบแล้ว (Active Session View)**: หากเข้าสู่ระบบอยู่แล้วแล้วกดย้อนกลับมาที่หน้าแรก (`index.html`) หรือหน้าล็อกอิน (`login.html`) กล่องฟอร์มจะเปลี่ยนเป็นการ์ด **"พร้อมใช้บริการของคุณ"** อัตโนมัติทันที พร้อมปุ่ม **"ไปยังบัญชีของฉัน →"** สีส้มสดใส (เมื่อแตะหรือกดใช้งานจะเปลี่ยนเป็นเฉดสีส้มจางๆ ละมุนตา ไม่เปลี่ยนเป็นสีน้ำเงิน) และมีทางลัดออกจากระบบ/สลับบัญชี (พร้อมกล่องถามยืนยันก่อนออกจากระบบเสมอ)

### 2. หน้าลงทะเบียนผู้เช่าแผงค้าใหม่ (Registration - `register.html`)
- **ดีไซน์พรีเมียม 2 คอลัมน์ กระชับและรวดเร็ว**:
  - **ฝั่งซ้าย (แถบสีส้มเข้ม Vibrant Orange)**: แนะนำขั้นตอน 2 สเต็ป (`01 กรอกข้อมูลผู้ใช้งานและรหัสผ่าน`, `02 เข้าสู่ระบบและเลือกแผงค้าในหน้าชำระเงิน`) พร้อมลิงก์ด่วนเข้าสู่ระบบ
  - **ฝั่งขวา (แบบฟอร์มลงทะเบียน)**:
    - **ข้อมูลผู้ใช้งานและรหัสผ่าน**: เลือกประเภทผู้ใช้งานแบบ Interactive Cards (**บุคคลธรรมดา** / **นิติบุคคล / ร้านค้า**), ชื่อ-นามสกุล, เบอร์โทรศัพท์มือถือ, รหัสผ่าน, และยืนยันรหัสผ่าน (พร้อมปุ่มไอคอนดวงตากดเปิด/ปิดดูรหัสผ่านทั้งสองช่อง)
    - **ปรับลดขั้นตอนเพื่อความสะดวก**: นำส่วนที่ 2 (ข้อมูลแผงค้าและที่ตั้งร้าน) ออกจากหน้าลงทะเบียนอย่างสมบูรณ์ เพื่อลดความยุ่งยากซับซ้อน โดยผู้เช่าสามารถไปเลือกหมายเลขแผงค้าและชำระค่าธรรมเนียมได้โดยตรงในหน้าชำระเงิน (`payment.html`)
    - **ระบบตรวจสอบความถูกต้อง**: ตรวจสอบว่ารหัสผ่านและยืนยันรหัสผ่านตรงกัน และเบอร์โทรศัพท์ถูกต้องตามรูปแบบมาตรฐาน
- **บันทึกข้อมูลและใช้งานได้จริงทันที**: ข้อมูลลงทะเบียนถูกบันทึกลงในฐานข้อมูล/หน่วยความจำ (`smartpay_users` และ Backend API)
- **โมดอลแจ้งเตือนลงทะเบียนสำเร็จ**: ป๊อปอัปกลางจอแสดงความยินดีต้อนรับชื่อจริงที่สมัคร เบอร์โทรศัพท์ พร้อมปุ่มนำทาง **"ไปยังบัญชีของฉัน →"** เข้าสู่หน้า `account.html` ทันที

### 3. หน้าบัญชีผู้ใช้งาน (Vendor Profile & Dashboard - `account.html`)
- **หน้าปลายทางหลักหลังเข้าสู่ระบบสำเร็จ**: รวบรวมข้อมูลผู้เช่า สรุปภาพรวมสถานะรอบบิล และ 4 เมนูลัดการบริการตลาดของเทศบาล
- **แสดงข้อมูลผู้ใช้จริงแบบไดนามิก (Dynamic Vendor Data & Layout Balance)**:
  - ชื่อ-นามสกุล และหมายเลขแผงค้า/โซนตลาด ที่ดึงจากข้อมูลจริงในระบบ (ไม่ยึดติดหรือฮาร์ดโค้ดค่าคงที่แผงค้า A-10 อีกต่อไป หากยังไม่ได้เลือกจะแสดงสถานะแนะนำให้ระบุในหน้าชำระเงิน)
  - **สถานะบัญชีปรับตามระบบหลังบ้านจริง**: ป้ายสถานะบัญชีผู้เช่าจะปรับเปลี่ยนสีและข้อความตามที่เจ้าหน้าที่เทศบาลกำหนดในระบบหลังบ้าน (`ปกติ`, `รอต่อสัญญา`, `ระงับการใช้งาน`, `ยกเลิกสัญญา`) อย่างแม่นยำ
  - **จัดระเบียบช่องข้อมูลให้กว้างสมดุลเท่ากัน (Symmetrical Equal-Width Grid)**: จัดตารางแสดงข้อมูลผู้เช่าให้มีความกว้างสมมาตรเท่ากันทุกช่อง สวยงาม อ่านง่าย สบายตา
- **วิดเจ็ตสรุปสถานะการชำระค่าเช่าแผงประจำปีงบประมาณ 2570 (Rental Progress Widget)**:
  - แสดงจำนวนเดือนที่ชำระแล้วแบบเรียลไทม์ เช่น **"ชำระแล้ว X / 12 เดือน"**
  - แถบความคืบหน้า (Progress Bar) สีส้มสดใส คำนวณเป็นเปอร์เซ็นต์ตามจริง
  - แจกแจงยอดเงินที่ชำระแล้ว และยอดเงินคงเหลือประจำปีงบประมาณ พร้อมปุ่มทางลัด **"ชำระเงินค่าเช่าแผง →"**
- **4 การ์ดเมนูลัดบริการท้องถิ่น (2x2 Grid)**:
  1. **ชำระค่าบริการ →**: ตรวจสอบค่าเช่าแผงของคุณ (เชื่อมโยงไปยัง `payment.html`)
  2. **ประวัติการใช้งาน →**: ติดตามการชำระเงิน ใบเสร็จ และคำร้อง (เชื่อมโยงไปยัง `history.html`)
  3. **แจ้งคำร้อง →**: ส่งเรื่องให้เจ้าหน้าที่ตรวจสอบ (เปิดโมดอลแจ้งคำร้อง/เรื่องร้องเรียนแผงค้า)
  4. **ติดต่อเทศบาล →**: สอบถามข้อมูลค่าเช่าแผง (เชื่อมโยงไปยังส่วนช่องทางติดต่อ อบต./เทศบาล)
- **ระบบรักษาความปลอดภัย (Auth Guard)**: หากยังไม่ได้เข้าสู่ระบบและพยายามเปิดหน้านี้ จะถูกส่งกลับไปหน้าแรกทันที

### 4. หน้าชำระเงินค่าเช่าแผงค้า (Stall Rental Payment & Direct Fill-in Form - `payment.html`)
- **ระบบป้องกันหน้า (Auth Guard)**: ตรวจสอบสถานะการเข้าสู่ระบบ หากยังไม่ได้ล็อกอินจะถูกส่งกลับไปหน้าแรกทันที
- **ระบบเลือกแผงค้าและตรวจสอบการครอบครองแบบเรียลไทม์ (Real-Time Stall Occupancy & Duplicate Protection)**:
  - **ดรอปดาวน์เลือกแผงค้า A-1 ถึง A-15 พร้อมตรวจสอบสถานะสด**:
    - **แผงที่มีผู้เช่าแล้ว**: แสดงสถานะ `- ✕ มีผู้เช่าแล้ว` และ **ถูกปิด (Disabled) สีเทา ป้องกันการกดเลือกซ้ำ**
    - **คุ้มครองความเป็นส่วนตัว (Privacy Protection)**: นำชื่อผู้เช่ารายอื่นออกจากตัวเลือกทั้งหมด เพื่อไม่ให้รั่วไหลหรือเปิดเผยข้อมูลส่วนบุคคลของผู้เช่ารายอื่นแก่สาธารณะ
    - **แผงของผู้เช่าเอง**: ไฮไลต์ด้วยข้อความ `- ✓ แผงค้าของคุณ`
    - **แผงที่ยังไม่มีผู้เช่า**: แสดง `- ว่าง (เลือกได้)`
    - **เลือกแผงว่างให้อัตโนมัติสำหรับผู้เช่าใหม่**: ตัดระบบเดิมที่บังคับตกเป็น A-10 ออก หากผู้เช่าใหม่ยังไม่มีแผงค้า ระบบจะเลือกแผงแรกที่ยังว่างอยู่ให้อัตโนมัติ (เช่น A-1)
  - **กล่องข้อความแจ้งเตือนสถานะแผงค้าสด (`#stallOccupancyHint`)**: แสดงสถานะใต้ช่องเลือกแผงค้าทันทีเมื่อเปลี่ยนแผง
  - **จัดช่องกรอกเท่ากันสมดุล (Symmetrical Layout)**: จัดความกว้างและความสูงของช่องหมายเลขแผงค้าและโซนตลาดให้เท่ากัน สวยงามและสมดุล
- **แบบฟอร์มชำระค่าเช่าแผงค้าพร้อมระบบเลือกรอบเดือน (Month Selection Form)**:
  - **ตารางเลือกรอบเดือน 12 เดือน (ม.ค. - ธ.ค.) เลือกได้อิสระ**: แสดงการ์ดรอบเดือนเรียงลำดับ ม.ค. ถึง ธ.ค. ผู้เช่าสามารถแตะเลือกหรือแตะยกเลิกเดือนใดๆ ได้อย่างอิสระ ไม่มีล็อกหรือบังคับค่าเริ่มต้น
  - **ระบบบังคับเลือกรอบเดือนก่อนชำระเงิน**: หากไม่ได้เลือกเดือนใดไว้ (0 เดือน) แล้วกดปุ่มชำระเงิน ระบบจะสั่นเตือนและแจ้งเตือน `⚠️ กรุณาเลือกรอบเดือนที่ต้องการชำระอย่างน้อย 1 เดือน` ป้องกันการทำรายการโดยไม่ระบุเดือน

- **ระบบจัดการคำร้องและเรื่องร้องเรียน (Complaint Management)**:
  - เรียกดูรายการคำร้องทั้งหมดที่ส่งมาจากผู้เช่าแผง
  - คัดกรองตามสถานะ: ทั้งหมด, รอดำเนินการ, กำลังดำเนินการ, แก้ไขเรียบร้อยแล้ว
  - ปุ่ม **"จัดการคำร้อง"**: อัปเดตสถานะ พร้อมพิมพ์ข้อความตอบกลับของเจ้าหน้าที่ (Officer Reply) บันทึกลงฐานข้อมูลและส่งต่อให้ผู้เช่าเห็นในหน้าประวัติ
- **การออกใบเสร็จรับเงินทางการ (Official Municipal Utility Receipt Slip)**:
  - ถอดแบบมาจากใบเสร็จ/ใบแจ้งหนี้สาธารณูปโภคและราชการ (Provincial Utility / Municipal Bill Layout):
    - **มุมซ้ายบน**: โลโก้จำลอง **GURU IT Solution** ขนาดเล็ก พร้อมข้อมูล Call Center 1662 และช่องทางติดต่อ
    - **มุมขวาบน**: หัวเอกสารราชการทางการ **"ใบเสร็จรับเงินค่าเช่าแผงค้า"** สังกัดกองคลัง เทศบาลตำบล / อบต. และสาขาตลาดสดเทศบาล
    - **ตารางกริดขอบสีน้ำเงิน 3 คอลัมน์**: เลขที่ใบเสร็จ, รหัสผู้เช่า/แผงค้า, รหัสหน่วยงาน (`1183-64`), วันที่ออก, งวดประจำเดือน, และโซนเส้นทาง (`020005.186`)
    - **ข้อมูลผู้เช่าและที่ตั้งแผงค้า**: ชื่อนายสมชาย สุขสมบูรณ์ และตำแหน่งแผงค้า
    - **ตารางแจกแจงค่าธรรมเนียมเส้นตารางสีน้ำเงินคมชัด**: ค่าเช่าพื้นที่แผงค้า, ค่าบำรุงรักษาตลาดและส่วนกลาง, ค่าบริการจัดเก็บขยะและดูแลความสะอาด, รวมเงิน, ภาษีมูลค่าเพิ่ม (VAT), และยอดเงินที่ชำระทั้งสิ้น
    - **แถบบาร์โค้ดแนวตั้ง (Vertical Barcode Strip)**: กราฟิกบาร์โค้ดตามแนวตั้งฝั่งขวาของใบเสร็จตามแบบเอกสารจริง
    - **ตรายางทางการ PAID**: ปั๊มตรายางสีแดง `PAID · ชำระแล้ว` พร้อมวันที่ และช่องลายมือชื่อนายตรวจตลาด/เจ้าหน้าที่การเงิน กองคลังเทศบาล
    - **ปุ่มสั่งพิมพ์ (Print Ready)**: รองรับการพิมพ์จริงผ่านเบราว์เซอร์ พร้อมคำสั่ง `@media print` ซ่อนฉากหลังและปุ่มกด เหลือเฉพาะใบเสร็จรับเงินอย่างประณีต

## 🗄️ สถาปัตยกรรมการจัดเก็บข้อมูล (Data Storage Architecture)

## 🎨 การออกแบบและอัตลักษณ์สีส้ม (Design & Vibrant Orange Branding)

- **ชุดสี Modern Vibrant Orange Palette**: สอดคล้องกับสีส้มเอกลักษณ์ของแบรนด์ **GURU IT Solution**
  - **Primary Orange (`#ea580c` / `#ff5500`)**: สีหลักสำหรับปุ่ม, ลิงก์, แท็บที่เลือก, และไอคอนแผงค้า
  - **Deep Amber / Dark Orange (`#c2410c`, `#9a3412`, `#431407`)**: สีส้มเข้มและน้ำตาลอำพันสำหรับพื้นหลัง Hero, หัวข้อใหญ่, และแถบสรุปยอด
  - **Warm Tint Paper (`#fffaf5`, `#fff7ed`, `#ffedd5`)**: สีพื้นหลังหน้าเว็บและการ์ดข้อมูลผู้เช่าที่นุ่มนวล สบายตา
  - **Success Green (`#10b981`, `#059669`, `#ecfdf5`)**: สีเขียวสำหรับป๊อปอัปแจ้งเตือนเข้าสู่ระบบสำเร็จ (✓), แถบความคืบหน้า (Progress Fill), ป้ายรอบบิลที่ชำระแล้ว, และตรายางใบเสร็จ
  - **Neutral Modal Backdrop (`rgba(15, 23, 42, 0.45)`)**: สีพื้นหลังโปร่งแสงโทนเทาเข้มมาตรฐานสำหรับโมดอลและหน้าต่างแจ้งเตือนทั้งหมด (ตัดโทนส้มทึบแสงเดิมออก เพื่อความสะอาดตาและโฟกัสที่การ์ดแจ้งเตือนอย่างลงตัว)
  - **Error Coral (`#ef4444`)**: สีแดงสำหรับป๊อปอัปแจ้งเตือนข้อผิดพลาด (✕)
- **ตราสัญลักษณ์ทางการ (Official GURU IT Logo)**: ตัวอักษร "G" และ "URU" โทนสีน้ำเงินเอกลักษณ์ (`#0066cc`) ตัดกับ "IT" สีส้มสดใส (`#ff3300`) และคำบรรยาย "Solution Co., Ltd." สีเทา ถูกต้องตามอัตลักษณ์และสัดส่วนต้นฉบับของบริษัท
- **แถบนำทางส่วนหัวล็อคอยู่กับที่ (Locked Fixed Navbar)**: ตรึงแถบ Header Bar อยู่ด้านบนสุดของหน้าจอด้วย `position: fixed` ตลอดเวลาในทุกหน้า ไม่เลื่อนหรือขยับหนีไปไหนเมื่อผู้ใช้เลื่อนหน้าจอลง (Scroll down) ทำให้เข้าถึงเมนูและโลโก้ได้อย่างสะดวกต่อเนื่อง
- **เอฟเฟกต์ปฏิสัมพันธ์สัมผัสโทนส้มละมุน (Soft Light Orange Touch & Hover Interactions)**: ปรับแต่งปุ่มดำเนินการสำคัญ เช่น ปุ่ม **"ไปยังบัญชีของฉัน →"** (`.btn-goto-account`) และปุ่มส่งข้อมูล เมื่อนำเมาส์ชี้ แตะ หรือกดค้าง (`:hover`, `:focus`, `:active`) จะเปลี่ยนเป็นเฉดสีส้มพาสเทลจางๆ นุ่มนวล (`linear-gradient(135deg, #fb923c 0%, #fdba74 100%)`) พร้อมเงาสีส้มโปร่งแสง ปราศจากสีน้ำเงินเดิมอย่างสิ้นเชิง
- **ระบบปุ่มดวงตาแสดง/ซ่อนรหัสผ่าน (Show/Hide Password Toggle)**: ติดตั้งไอคอนรูปดวงตาในทุกแบบฟอร์มที่มีช่องรหัสผ่าน (`index.html`, `login.html`, `register.html`) รองรับการคลิกสลับเพื่อแสดงตัวเลขรหัสผ่านหรือซ่อนไว้ตามต้องการ
- **การจัดวางแบบกึ่งกลางบนมือถือ (Mobile-Friendly Centered Layout)**:
  - ทุกการ์ด ทุกฟอร์ม และทุกคอนเทนต์ถูกตั้งค่า `margin: 0 auto;` และ `box-sizing: border-box;` เพื่อให้กึ่งกลางหน้าจอเสมอเมื่อแสดงผลบนสมาร์ตโฟน
  - ป้องกันปัญหาหน้าจอเอียงซ้ายหรือขอบล้นด้วย `overflow-x: hidden;`
- **ระบบป้องกัน BFCache (Back-Forward Cache Cleanup)**:
  - ตรวจจับอีเวนต์ `pageshow` และ `pagehide` เพื่อล้างโมดอลป๊อปอัปแจ้งเตือนออกจาก DOM ป้องกันปัญหาป๊อปอัปค้างหน้าจอเมื่อผู้ใช้กดปุ่มย้อนกลับของเว็บเบราว์เซอร์

## 🗄️ การตั้งค่าฐานข้อมูล (MySQL / PostgreSQL)

Backend รองรับทั้ง **MySQL** (ค่าเริ่มต้น) และ **PostgreSQL** โดยตั้งค่าได้ที่ไฟล์ `backend/.env`:

### 1. กรณีใช้ MySQL (เช่น XAMPP / MariaDB / MySQL Server)
```env
DB_TYPE=mysql
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=
MYSQL_DATABASE=marketpay_db
```
- เปิดโปรแกรม MySQL (เช่น Start MySQL ใน XAMPP Control Panel)
- สร้างฐานข้อมูลชื่อ `marketpay_db` ใน phpMyAdmin หรือรันคำสั่ง:
  ```sql
  CREATE DATABASE marketpay_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```
- ตัวระบบจะสร้างตาราง `users`, `payments`, `payment_months`, `complaints` ให้โดยอัตโนมัติ หรือสามารถนำเข้าไฟล์ [backend/config/schema.sql](file:///c:/Users/Admin/OneDrive%20-%20Guru%20IT%20Solutions%20Co.,%20Ltd/Desktop/MarketPay/backend/config/schema.sql) ได้ทันที

### 2. กรณีใช้ PostgreSQL
```env
DB_TYPE=postgres
PG_HOST=localhost
PG_PORT=5432
PG_USER=postgres
PG_PASSWORD=postgres
PG_DATABASE=marketpay_db
```

### 3. ระบบรองรับกรณี Database Server ยังไม่เปิด (Smart Auto-Fallback)
หากยังไม่ได้เปิดโปรแกรม MySQL/PostgreSQL เซิร์ฟเวอร์ Backend จะเปิดใช้งาน **Fallback In-Memory Storage** ให้อัตโนมัติ โดยไม่เกิด Error ขัดข้อง ช่วยให้คุณสามารถพัฒนาและทดสอบหน้าบ้านได้ทันที และเมื่อเปิด Database Server แล้ว ระบบจะเชื่อมต่อและบันทึกลงฐานข้อมูลจริง

| **16. ปรับการคำนวณยอดเงินรายรับรวม (Accurate Revenue Metric)** | ปรับปรุงตรรกะการคำนวณ `totalRevenue` ทั้งในฝั่ง SQL และ Fallback Store ให้ตัดยอดเงินของรายการที่ถูกปฏิเสธ (Rejected) และรายการที่รอตรวจสอบ (Pending) ออก เพื่อให้ตัวเลขรายได้บนแดชบอร์ดสะท้อนยอดเงินที่ได้รับจริงและอนุมัติแล้วเท่านั้น |
| **17. แก้ไขการลบประวัติชำระเงินในเมนูแอดมิน (Payment Deletion & Month Status Sync)** | ปรับปรุงระบบลบรายการชำระเงินในฝั่งแอดมิน ให้ล้าง/อัปเดตข้อมูลรอบเดือนที่ผูกไว้ในระบบ (`payment_months`) อย่างถูกต้อง ป้องกันปัญหาสถานะชำระแล้วไม่ยอมหายเมื่อเจ้าหน้าที่ทำการลบรายการ |
| **18. อัปเดตชุดภาพข่าวสารและแบนเนอร์ประชาสัมพันธ์** | ปรับเปลี่ยนภาพถ่ายข่าวสารประชาสัมพันธ์แผงค้าและงานชำระค่าธรรมเนียมให้เป็นภาพจริง คมชัด โทนอบอุ่น สอดคล้องกับบรรยากาศตลาดสดเทศบาล |
| **19. แก้ไขและยกระดับระบบตรวจสอบสลิป (Slip Inspection & Verification Workflow)** | แก้ไขข้อผิดพลาด JavaScript (`ReferenceError: isApproved`) ในฟังก์ชันเรนเดอร์รายการชำระเงิน, ปรับปรุงระบบสลับแท็บและตัวกรองสถานะ (`pending`, `approved`, `all`) ให้อัปเดตทันที, เพิ่มหน้าต่างแสดงผลเมื่อไม่พบข้อมูล (Empty State) พร้อมปุ่มกดเคลียร์ตัวกรองอัตโนมัติ และปรับปรุงโมดอลซูมตรวจสอบสลิปให้อนุมัติ/ปฏิเสธพร้อมระบุเหตุผลได้อย่างสมบูรณ์แบบ |
| **20. ปรับปรุงหน้าลงทะเบียน (Streamlined Registration)** | ปรับปรุงหน้า `register.html` โดยนำส่วนที่ 2 (ข้อมูลแผงค้าและที่ตั้งร้าน) ออกอย่างสมบูรณ์ เพื่อลดขั้นตอนการสมัคร โดยผู้เช่าสามารถไปเลือกแผงค้าและชำระค่าธรรมเนียมได้โดยตรงในหน้าชำระเงิน |
| **21. ปรับปรุงหน้าบัญชีผู้เช่าและสถานะไดนามิก (Dynamic Vendor Profile & Status)** | นำข้อความแผงค้า A-10 แบบคงที่ออกจากหน้า `account.html` ให้แสดงตามข้อมูลแผงค้าจริง และปรับปรุงป้ายสถานะบัญชีให้แสดงผลตรงตามที่ระบบหลังบ้านเลือก (`ปกติ`, `รอต่อสัญญา`, `ระงับการใช้งาน`, `ยกเลิกสัญญา`) พร้อมสีสันที่สื่อความหมายชัดเจน |
| **22. จัดระเบียบช่องกรอกข้อมูลให้กว้างเท่ากันสมดุล (Symmetrical Form Layout)** | ปรับสไตล์ CSS ของการ์ดข้อมูลผู้เช่าและช่องระบุแผงค้า/โซนตลาดในหน้าชำระเงินให้มีความกว้างและความสูงเท่ากัน สมดุล ดูประณีตและเป็นระเบียบ |
| **23. ล็อคแถบส่วนหัวในระบบหลังบ้าน (Sticky Fixed Admin Header Bar)** | ปรับแต่งแถบ Header ของหน้า `admin.html` ให้ตรึงอยู่ด้านบนตลอดเวลา (`position: sticky; top: 0`) ไม่เลื่อนหายไปตามการ Scroll พร้อมเอฟเฟกต์เบลอและเงาตกกระทบ เพื่อความสะดวกในการค้นหาและกรองข้อมูล |
| **24. ดึงข้อมูลเลขแผงค้าตามที่เลือกจริงในระบบแอดมิน (Dynamic Stall Display in Admin)** | แก้ไขตารางข้อมูลการชำระเงินและข้อมูลผู้เช่าให้ดึงเลขแผงค้าจริงตามที่เลือก พร้อมเพิ่มตัวเลือกแผงค้า A-1 ถึง A-15 ในโมดอลแก้ไขข้อมูลผู้เช่าและรายการชำระเงิน |
| **25. ระบบป้องกันการเลือกล็อคแผงค้าซ้ำ (Real-Time Stall Occupancy & Duplicate Prevention)** | พัฒนาระบบตรวจสอบสถานะแผงค้าแบบสด (`/api/payments/stalls/status`) ปิดการเลือกแผงที่มีผู้เช่าแล้ว (`disabled`) ไฮไลต์แผงของผู้เช่าเอง (`✓ แผงค้าของคุณ`) และเลือกแผงว่างแผงแรกให้อัตโนมัติสำหรับผู้เช่าใหม่ พร้อมระบบตรวจสอบ Backend Conflict Validation ปฏิเสธการบันทึกซ้ำด้วยรหัส HTTP 409 |
| **26. คุ้มครองข้อมูลส่วนบุคคลโดยไม่แสดงชื่อผู้เช่าในรายการล็อคที่มีเจ้าของแล้ว (Privacy Protection: Hide Occupant Name)** | ปรับแต่งตัวเลือกแผงค้าในดรอปดาวน์และข้อความแจ้งเตือนทั้งหมด ให้แสดงเฉพาะ `✕ มีผู้เช่าแล้ว` โดยนำชื่อและเบอร์โทรศัพท์ของผู้เช่าเดิมในวงเล็บออกทั้งหมด เพื่อความปลอดภัยและความเป็นส่วนตัวของข้อมูลผู้เช่า |
